Política de privacidad

Última actualización: 16 de noviembre de 2026

1. Quién la usa

DelmoUP es una aplicación de escritorio de uso personal del creador de contenido @soydelmo_. No se ofrece al público y no tiene usuarios registrados.

2. Qué datos usa

Cuando el titular conecta su cuenta de Google / YouTube, la aplicación accede únicamente a:

  • Subida de vídeos (permiso youtube.upload): para subir sus propios vídeos con título, descripción, etiquetas, miniatura y fecha de publicación.
  • Datos básicos del canal (permiso youtube.readonly): solo el nombre, el identificador y la imagen del canal, para mostrar qué cuenta está conectada.

No se leen comentarios, estadísticas, suscriptores ni ningún otro dato de la cuenta.

3. Dónde se guardan

  • Todo se guarda solo en el ordenador del titular. DelmoUP no tiene servidores propios.
  • Los tokens de acceso se guardan cifrados con el cifrado del sistema de Windows.
  • Los vídeos y textos solo se envían directamente a la plataforma correspondiente (YouTube, Instagram o TikTok) cuando el titular decide publicarlos.

4. Con quién se comparten

Con nadie. Los datos no se venden, no se ceden a terceros y no se usan para publicidad ni para entrenar modelos. El uso de la información recibida de las API de Google cumple la Política de datos de usuario de los servicios API de Google, incluidos los requisitos de uso limitado.

5. Servicios de terceros

La aplicación usa los Servicios API de YouTube. Se aplica la Política de privacidad de Google y las Condiciones de servicio de YouTube.

6. Cómo retirar el acceso y borrar los datos

  • Desde la propia aplicación: Cuentas → Desconectar (revoca el acceso y borra el token guardado).
  • Desde Google, en cualquier momento: myaccount.google.com/permissions.
  • Desinstalar la aplicación y borrar su carpeta de datos elimina toda la información guardada.

7. Contacto
