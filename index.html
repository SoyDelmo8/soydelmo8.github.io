DelmoUP

Programador de vídeos cortos de @soydelmo_

¿Qué es?

DelmoUP es una aplicación de escritorio para Windows de uso personal. Sirve para programar y publicar los vídeos verticales del creador @soydelmo_ en su propio canal de YouTube (Shorts) y en sus propias cuentas de Instagram y TikTok.

  • Sube los vídeos con su título, descripción, hashtags y miniatura.
  • Los programa para que se publiquen a la hora elegida.
  • Muestra un calendario con todas las publicaciones.

No es un servicio público: no tiene usuarios registrados ni servidores propios. Todo funciona en el ordenador del creador y solo se conecta a las cuentas que él mismo autoriza.

Uso de los Servicios API de YouTube

Usa los Servicios API de YouTube

DelmoUP usa los Servicios API de YouTube para subir vídeos y programar su publicación. Al usar esta aplicación aceptas las Condiciones de servicio de YouTube y se aplica la Política de privacidad de Google.
